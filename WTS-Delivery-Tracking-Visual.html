STOP READING
Observations from Order History Review
  • 1. No order grouping: Orders for the same address (e.g., UA18801 and UA18788 for Dalco Services) appear as separate entries with no way to associate them from the landing page.
  • 2. Missing delivery date: Only the order placed date is displayed. No delivery date visible, making it harder to track upcoming deliveries and their statuses.
  • 3. Delivery notes workflow flaw: Users must enter ground drop / roof drop instructions in the notes section at the very last checkout stage. This should be captured early in the ordering flow.
  • 4. Filter state bug: After applying a status filter (e.g., "Delivered"), clicking into an order detail and going back preserves the filter logic but removes the visual chip indicator — confusing the user about what's currently filtered.
  • 5. Photo display issues: Delivery images are compressed vertically (portrait photos displayed in landscape). Clicking expands to landscape mode by stretching the portrait image horizontally. No carousel — users must click in and out of each image individually.
